从一条提示词到多图输出、尺寸控制、代理、脚本化 JSON 与更新管理。本页聚焦“怎样用”，参数的完整定义请查阅 Reference。

生成图片查看完整参数

三个命令，一条清晰路径

doctor

验证配置、代理、模型列表。不会提交图片生成请求。

generate

提交一次图片请求，验证响应与像素尺寸，并安全保存文件。

update

从允许的公开 Release 渠道检查版本；只有通过来源、文件名、大小、SHA-256 和 wheel 元数据校验后，才会安排更新。

生成图片

基础命令

gpt-image generate "极简产品摄影，一台透明外壳的未来相机" \
  --size 1024x1024 --quality high \
  -o ./artifacts/camera.png

尺寸与别名

值实际请求适合内容
square1024x1024头像、图标、方形封面
landscape1536x1024电影画面、网页横幅
portrait1024x1536海报、角色全身像
auto不发送 size让兼容 API 使用自身默认值

显式指定尺寸时，服务端若返回不同画布，CLI 默认报错并且不写文件。确实希望得到精确画布时，主动加入 --fit-output-size，它会居中裁切并用 Lanczos 缩放为目标尺寸。

gpt-image generate "竖版科幻电影海报，无文字" \
  --size portrait --fit-output-size \
  -o ./artifacts/poster.png
裁切是显式选择

--fit-output-size 可能移除图片边缘内容。默认严格拒绝不匹配画布，是为了避免悄悄改变构图。

一次生成多张

-n 支持 1 到 10。输出为多张时，CLI 会在文件名后追加从 1 开始的序号。

gpt-image generate "月球温室里的小型机器人" \
  -n 3 --size landscape \
  -o ./artifacts/moon-greenhouse.png

结果路径为 moon-greenhouse-1.png、moon-greenhouse-2.png 与 moon-greenhouse-3.png。所有响应图片会先完成验证，默认也会先检查所有目标文件是否已存在。

从文件读取长提示词

复杂提示词可以保存在 UTF-8 文本文件中，避免 shell 引号和换行转义：

gpt-image generate --prompt-file ./prompt.txt \
  --size landscape --quality high \
  -o ./artifacts/result.png

位置参数提示词与 --prompt-file 不能同时使用，空文件也会被拒绝。

安全管理输出

  • 自动扩展名：输出路径没有扩展名时，根据实际图片格式补充 .png、.jpg、.webp 或 .gif。
  • 原子写入：先在目标目录写临时文件、刷新到磁盘，再原子替换目标。
  • 默认不覆盖：已有文件会触发错误；只有明确加入 --overwrite 才覆盖。
  • 响应上限：默认拒绝超过 150 MB 的图片 API 响应，可用 --max-response-mb 调整。

代理与网络

代理优先级是：显式 --proxy → HTTP_PROXY / HTTPS_PROXY / ALL_PROXY → 已启用的 Windows 系统代理 → 直连。

gpt-image doctor --proxy http://127.0.0.1:7890
gpt-image doctor --no-proxy

--proxy 与 --no-proxy 不能同时使用。代理 URL 中的用户名与密码不会出现在诊断输出，显示时仅保留协议、主机、端口和路径。

超时与重连

  • --connect-timeout 默认 30 秒。
  • --connect-retries 默认 2，只重试请求尚未提交的连接建立失败。
  • --timeout 默认 1800 秒，控制图片生成响应等待时间。
  • --download-timeout 默认 300 秒，用于下载 URL 响应中的图片。
不会自动重试可能已计费的请求

POST 已提交后出现读超时或连接中断，CLI 会提示可能已经计费，并停止自动重试。请先检查供应商后台，再决定是否手动重新生成。

脚本与 JSON 输出

doctor、generate 和 update 都支持 --json。JSON 模式不会混入等待心跳或自动更新提示，适合 CI 和脚本解析。

gpt-image generate "blue glass sculpture" \
  --size square -o ./artifacts/sculpture.png \
  --dry-run --json

生成成功时，images 数组包含绝对路径、宽高、格式、字节数和响应来源。不要依赖非 JSON 模式的缩进展示来编写解析器。

检查与安装更新

gpt-image update --check
gpt-image update --check --json
gpt-image update

交互式 doctor 或 generate 成功后，CLI 最多每 24 小时低频检查一次正式 Release。发现可信新版本时，它会下载并验证 wheel，然后让独立助手在当前命令退出后运行 uv tool install --force。

如果不希望自动检查：

# PowerShell
$env:GPT_IMAGE_DISABLE_UPDATE_CHECK = "1"

# Bash / Zsh
export GPT_IMAGE_DISABLE_UPDATE_CHECK=1

非 uv tool 安装不会被擅自替换；此时应通过最初安装它的包管理器更新。
