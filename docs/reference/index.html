一处查全。

这里是精确查阅入口。需要学习路径请从 Getting Started 开始；需要完成具体任务请使用 Guides and Tutorials。

全局命令

gpt-image [-h] [--version] {doctor,generate,update} ...
选项 / 命令说明
-h, --help显示当前层级帮助并退出
--version输出 gpt-image X.Y.Z 并退出
doctor解析配置并检查模型列表
generate生成、验证和保存图片
update检查公开 Release，并安装验证过的新 wheel

连接参数

doctor 与 generate 共享以下参数。

参数默认值说明
--api-base URL环境或 CC-Switch覆盖 OpenAI 兼容 API base；Key 仍必须来自环境变量
--cc-switch-db PATH~/.cc-switch/cc-switch.db直接环境配置不存在时读取的数据库
--allow-httpfalse明确允许非 HTTPS 远程 API；localhost 无需该参数
--proxy URL自动解析显式 HTTP(S) 代理
--no-proxyfalse忽略代理环境变量与 Windows 系统代理
--connect-timeout SEC30连接建立超时，必须大于 0
--connect-retries N2只用于连接建立失败，不能为负数

doctor 参考

gpt-image doctor [连接参数] [--model MODEL] [--json]
参数默认值说明
--model MODELGPT_IMAGE_MODEL 或 gpt-image-2在供应商模型列表中检查的模型
--jsonfalse只输出单个机器可读 JSON 对象

JSON 字段

success、provider、source、api_base、endpoint、requested_model、model_available、image_models、proxy_mode、proxy。

generate 参考

gpt-image generate [连接参数] [PROMPT] -o OUTPUT [选项]
参数默认值说明
PROMPT无位置提示词；与 --prompt-file 二选一
--prompt-file PATH无读取 UTF-8 提示词
-o, --output PATH必填输出图片路径
--model MODELGPT_IMAGE_MODEL 或 gpt-image-2请求模型
--size VALUEautoauto、三个正式尺寸或三个别名
--quality VALUEautoauto / low / medium / high
--background VALUEautoauto / opaque
-n N1图片数量，1–10
--timeout SEC1800生成响应读取超时
--download-timeout SEC300URL 图片下载超时
--max-response-mb N150API 响应体上限
--overwritefalse明确允许覆盖目标文件
--fit-output-sizefalse居中裁切并缩放为显式请求尺寸
--dry-runfalse验证配置和参数，不提交生成请求
--no-progressfalse关闭文本与 JSONL 等待心跳
--jsonl-progressfalse向 stderr 输出脱敏 JSON Lines 进度事件
--jsonfalse只向 stdout 输出机器可读最终 JSON

JSONL 事件

request_started、connection_retry、request_submitted、heartbeat、completed、failed、interrupted。只有 connection_retry 可以发生在提交前；提交后的事件带有 request_submitted、possibly_billed 和 automatic_retry=false。Unix SIGTERM / SIGHUP、Windows Ctrl+Break（SIGBREAK）以及 Ctrl+C / KeyboardInterrupt 会产生 interrupted；SIGKILL、任务管理器结束进程或 TerminateProcess 等强制终止无法保证事件落盘。

成功 JSON 字段

基础字段包括 provider、source、endpoint、model、prompt_characters、output、parameters、response_format_omitted、proxy_mode 和 proxy。真实生成还包括 elapsed_seconds、request_id、response_bytes 与 images。

每个图片对象包含 path、width、height、format、bytes 和 source。

update 参考

gpt-image update [--check] [--source SOURCE] [--prerelease] [--proxy URL] [--no-proxy] [--timeout SEC] [--json]
参数默认值说明
--checkfalse只检查，不修改安装
--sourceautoauto / github / gitee / gitcode
--prereleasefalse允许选择预发布版本
--proxy URL自动解析仅用于更新流量的显式代理
--no-proxyfalse更新流量忽略代理
--timeout SEC30Release 查询与下载超时
--jsonfalse只输出机器可读 JSON

检查 JSON 字段

success、updated、current_version、latest_version、update_available、selected_release、checked_sources 与 source_errors。

环境变量

变量用途
GPT_IMAGE_API_BASE首选直接 API base
GPT_IMAGE_API_KEY首选直接 API Key
GPT_IMAGE_MODEL默认模型
OPENAI_BASE_URLAPI base 兼容回退
OPENAI_API_KEYAPI Key 兼容回退
HTTP_PROXY / HTTPS_PROXY / ALL_PROXYHTTPX 环境代理，大小写变量均识别
GPT_IMAGE_DISABLE_UPDATE_CHECK1、true、yes 或 on 关闭自动检查
GPT_IMAGE_STATE_DIR覆盖更新状态与工作目录，主要用于测试或受控部署
XDG_CACHE_HOMELinux 默认更新状态根目录
LOCALAPPDATAWindows 默认更新状态根目录
GITHUB_TOKEN / GITEE_TOKEN / GITCODE_TOKEN可选 Release API 鉴权；不会改变固定仓库边界

文件与状态路径

平台自动更新状态
Windows%LOCALAPPDATA%/gpt-image-2-cli/update-state.json
macOS~/Library/Caches/gpt-image-2-cli/update-state.json
Linux${XDG_CACHE_HOME:-~/.cache}/gpt-image-2-cli/update-state.json

状态仅记录上次检查时间、CLI 版本与平台，不记录 API Key、提示词或生成结果。

退出码

退出码含义
0命令成功；更新检查无新版也属于成功
1基础可预期 CLI 错误
2配置错误，或 argparse 参数用法错误
3生成、响应解析或图片写入错误
4doctor 已连接，但请求模型不可用
5Release 检查、验证、下载或自更新错误
128 + signal可处理的操作系统信号中断，例如 SIGTERM 通常为 143
130KeyboardInterrupt 中断

默认 Release 来源

名称固定仓库
GitHubLijinzh/gpt-image-2-cli
Giteeshan-yujun/gpt-image-2-cli
GitCodeLijinzh/gpt-image-2-cli

源不可用时，auto 可以继续检查其他配置源；没有任何可用源时返回 UPDATE ERROR。镜像只有实际配置、发布且匿名验证通过后，才应视为可用发布渠道。
