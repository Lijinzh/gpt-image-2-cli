DOCS / 03 / FEATURES

不是简单封装，
是可靠边界。

本工具围绕兼容中转、大图等待、计费风险、输出完整性和公开 Release 更新建立明确边界，同时保持单进程、同步调用与少量依赖。

图像生成能力

三种正式画布

1024x1024、1536x1024、1024x1536，并提供 square、landscape、portrait 别名。

1–10 张输出

一次请求支持多张图片，文件路径自动编号，写入前统一验证。

质量和背景

支持 auto、low、medium、high，背景支持 auto 与 opaque。

画布修正

默认严格拒绝尺寸不符；显式选择后可居中裁切并高质量缩放。

OpenAI 兼容响应

兼容 API 的响应并不总是统一。解析器会在有界深度内寻找并去重图片候选，支持：

  • data[].b64_json 与常见 base64 / image_base64 字段；
  • Base64 data URI；
  • HTTP(S) 图片 URL；
  • message.images[].image_url.url 等嵌套结构；
  • 直接图片响应；
  • 简单 Server-Sent Events 中的 JSON 数据行。

对 gpt-image-* 兼容路由，工具不会主动发送部分实现会拒绝的 response_format 参数。

面向大图的可靠性

  1. 长等待而非误判失败

    默认读取超时 30 分钟，并在交互终端输出等待心跳。

  2. 有限的安全重连

    只在请求尚未提交的连接建立阶段有限重连。

  3. 计费风险可见

    提交后断连不自动重试，并明确标记请求可能已经计费。

  4. 错误响应不伪装成功

    即使 HTTP 状态为 200，内嵌 error 对象也会被识别为失败。

图片与文件完整性

  • 使用 Pillow 解码并执行格式验证。
  • 读取实际宽高，显式尺寸不匹配时不写出文件。
  • 限制 API 响应和 Release 元数据大小，避免无界内存消耗。
  • 临时文件与目标文件位于同一目录，写入完成后原子替换。
  • 默认拒绝覆盖已有文件和多图输出中的任何冲突路径。

配置与代理发现

CC-Switch 只读发现

只读取当前用户数据库中的当前 Codex 供应商，不复制数据库，不打印 API Key。

标准环境变量

支持项目变量，也兼容 OPENAI_BASE_URL 与 OPENAI_API_KEY。

HTTPS 默认

远程 API 必须使用 HTTPS；localhost 自动允许 HTTP，其他 HTTP 地址需要明确 --allow-http。

代理优先级

显式代理、环境代理、Windows 系统代理与直连按确定顺序解析。

多源安全更新

更新器可检查项目配置允许的 GitHub、Gitee 与 GitCode Release，并从可用来源中选择最高版本。自动模式下，同一版本在多个镜像的 wheel 大小或 SHA-256 不一致时立即停止。

校验失败时的行为
固定仓库与 HTTPS 资产 URL拒绝跨仓库或不安全下载
版本、标签与 wheel 文件名拒绝名称或版本错配
声明大小与 SHA-256删除临时文件，不安排安装
wheel 包名与内部版本拒绝伪装或错误包
uv tool 环境识别提示通过原包管理器更新

验证完成后也不会在当前进程里替换自己。Windows 使用隐藏 PowerShell 助手，Linux/macOS 使用分离的 /bin/sh 助手，等待当前命令退出后重建隔离环境。

安全与隐私边界

  • 没有 --api-key 参数，降低密钥进入 shell 历史的风险。
  • 配置对象、错误与代理显示会清理凭据。
  • 不把 API Key、请求元数据或配置写入生成图片。
  • --json 和非交互调用不产生自动更新提示。
  • 静态网站反馈不会持有 GitHub Token，而是让用户在 GitHub 页面最终确认。

发现安全问题时，请阅读 SECURITY.md 并优先使用 GitHub 私密安全报告。

跨平台支持

CI 在 Ubuntu、Windows 和 macOS 上分别覆盖 Python 3.11 与 3.13。核心命令不依赖 Bash 或 PowerShell；只有退出后的更新助手按平台分支，并保持等价安装语义。

能力声明边界

跨平台测试证明 CLI 本身可运行，但第三方兼容 API、网络代理和模型可用性仍由使用者环境与供应商决定。
