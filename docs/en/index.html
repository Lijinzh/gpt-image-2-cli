01 ONE-LINE SETUP

Install once. Generate with confidence.

Install and configure gpt-image-2-cli from https://github.com/Lijinzh/gpt-image-2-cli. Prefer my current local CC-Switch Codex provider. First run gpt-image doctor and one no-charge --dry-run. Never print, copy, or save an API key. If CC-Switch is unavailable, guide me to set GPT_IMAGE_API_BASE and GPT_IMAGE_API_KEY locally, and do not ask me to paste a key into chat. After verification, tell me where the CLI was installed and give me one command that can generate an image.

Only this setup prompt is copied. Your real API key always stays on your own computer.

02 QUICK START

Four steps from install to image

  1. 01INSTALL

    Install the CLI from GitHub with uv.

    uv tool install "git+https://github.com/Lijinzh/gpt-image-2-cli.git"
  2. 02DOCTOR

    Inspect the provider, model, and network configuration without modifying it.

    gpt-image doctor
  3. 03DRY RUN

    Preview the request first, without generating an image or incurring model charges.

    gpt-image generate "..." --dry-run
  4. 04GENERATE

    Generate after reviewing the request, then validate the format and actual pixel dimensions.

    gpt-image generate "..." -o result.png

05 API KEY SAFETY

The repository is public. Your key stays local.

The CLI reads the current user's CC-Switch configuration or credentials from environment variables. It has no --api-key argument and does not write keys into images, request metadata, or public logs.

  • Never print bearer tokens or real API keys
  • Never commit .env, generated results, or request metadata
  • Never share providers or keys between collaborators
