这条路径适合第一次接触本工具的使用者。完成后，你会拥有一个由 uv tool 管理、能够安全读取本机配置并支持自动更新的跨平台 CLI。

开始安装已经安装？进入 Using

准备环境

GPT-Image 2 CLI 支持 Linux、macOS 与 Windows，需要 Python 3.11+ 和 uv。推荐使用 uv tool，因为它会为 CLI 创建独立环境，也是内置安全自更新能够识别和维护的安装方式。

检查 Python

python --version

版本应为 3.11 或更高。uv 也可以管理所需的 Python 运行时。

检查 uv

uv --version

如果命令不存在，请先按 uv 官方安装文档完成安装。

安装正式 Release

正式用户推荐从 GitHub Release 的通用 wheel 安装。wheel 固定到明确版本，便于验证来源，也能让内置更新器确认当前环境由 uv tool 管理。

uv tool install "https://github.com/Lijinzh/gpt-image-2-cli/releases/download/v0.2.4/gpt_image_2_cli-0.2.4-py3-none-any.whl"
gpt-image --version

如果安装成功但终端找不到命令，运行以下命令，然后重新打开终端：

uv tool update-shell
跨平台提示

上面的 uv tool install 命令在 PowerShell、Bash 与 Zsh 中完全相同，不要求管理员权限或 sudo。

源码版安装

需要跟踪 main 最新代码时，也可以从 Git 安装；正式使用仍建议优先采用 Release wheel。

uv tool install "git+https://github.com/Lijinzh/gpt-image-2-cli.git"

选择配置来源

方式 A：读取 CC-Switch

如果当前用户已使用 CC-Switch 配置 Codex 供应商，CLI 默认只读打开 ~/.cc-switch/cc-switch.db，解析当前 Codex 供应商。API Key 不会被复制到项目、终端输出或生成图片。

gpt-image doctor

方式 B：环境变量

Linux、CI 或不使用 CC-Switch 的用户，可以直接提供 OpenAI 兼容 API 地址与 Key。为了避免密钥进入 shell 历史，CLI 故意不提供 --api-key 参数。

PowerShell

$env:GPT_IMAGE_API_BASE = "https://relay.example/v1"
$env:GPT_IMAGE_API_KEY = "your-key"
$env:GPT_IMAGE_MODEL = "gpt-image-2"

Bash / Zsh

export GPT_IMAGE_API_BASE="https://relay.example/v1"
export GPT_IMAGE_API_KEY="your-key"
export GPT_IMAGE_MODEL="gpt-image-2"
不要公开凭据

不要把真实 Key 粘贴到聊天、Issue、日志、截图或仓库。示例中的 your-key 只是占位符。

运行不计费诊断

doctor 会解析配置、代理和模型列表，不提交图片生成请求。它适合在首次配置、切换供应商或排查网络问题后运行。

gpt-image doctor

成功输出会说明配置来源、脱敏后的 API 地址、目标模型是否存在以及代理模式。脚本中可使用稳定 JSON：

gpt-image doctor --json
模型不可用

如果连接成功但目标模型不在供应商返回的列表中，doctor 返回退出码 4。可用 --model 检查另一个模型名。

先预演，再生成

--dry-run 会验证提示词、尺寸、输出路径、配置与代理，并展示将要发送的非敏感参数，但不会发起可能计费的 POST 请求。

gpt-image generate "雨夜中的未来城市街道，电影感构图" \
  --size landscape --quality high \
  -o ./artifacts/city.png --dry-run

PowerShell 可将反斜杠续行改成反引号，或者把整条命令写在一行。

生成第一张图片

确认预演内容正确后，去掉 --dry-run：

gpt-image generate "雨夜中的未来城市街道，电影感构图" \
  --size landscape --quality high \
  -o ./artifacts/city.png

CLI 会等待响应、解析常见兼容格式、验证图片确实可被 Pillow 打开，并确认明确请求的像素尺寸。只有全部检查通过才会原子写入目标路径。

  1. 看到等待心跳

    大图可能需要数分钟。默认读取超时为 1800 秒。

  2. 检查结果摘要

    输出包含耗时、请求 ID、响应字节数、图片尺寸、格式和保存路径。

  3. 保留原文件

    目标已存在时默认拒绝覆盖；确认后才使用 --overwrite。
