DOCS / 04 / GUIDES AND TUTORIALS

按真实任务，
一步步完成。

选择与你当前环境最接近的场景，先诊断、再预演、最后执行可能计费或修改安装的操作。

教程：使用当前 CC-Switch 供应商

  1. 确认当前 Codex 供应商

    CLI 默认只读打开 ~/.cc-switch/cc-switch.db，不会修改数据库。

  2. 诊断模型与网络
    gpt-image doctor

    确认 source 来自 CC-Switch，且 model_available 为 true。

  3. 进行不计费预演
    gpt-image generate "暖色工作室中的复古机器人" --size square -o ./artifacts/robot.png --dry-run
  4. 提交生成
    gpt-image generate "暖色工作室中的复古机器人" --size square -o ./artifacts/robot.png
完成条件

终端返回 success: true，图片经过格式与 1024×1024 尺寸验证并保存到目标路径。

教程：不使用 CC-Switch

通过环境变量连接任意 OpenAI 兼容中转。示例 Key 必须替换为仅保存在本机环境中的真实值。

Windows PowerShell

$env:GPT_IMAGE_API_BASE = "https://relay.example/v1"
$env:GPT_IMAGE_API_KEY = "your-key"
gpt-image doctor

Linux / macOS

export GPT_IMAGE_API_BASE="https://relay.example/v1"
export GPT_IMAGE_API_KEY="your-key"
gpt-image doctor

远程 API 默认必须使用 HTTPS。localhost 自动允许 HTTP，其他 HTTP 地址只有明确加入 --allow-http 才会接受。

教程：在 CI 中做无计费验证

CI 不应该自动生成付费图片。使用 JSON 模式和 --dry-run 验证配置与参数，同时设置 GPT_IMAGE_DISABLE_UPDATE_CHECK=1。

gpt-image generate "ci smoke test" --size square -o ./artifacts/ci-smoke.png --dry-run --json

解析 JSON 并断言 success 与 dry_run 均为 true。需要测试真实模型列表时可以运行 doctor --json，但它会发出只读网络请求并需要 API 凭据。

教程：处理中转站忽略画布

  1. 先保持严格模式

    正常指定 --size landscape。若服务端返回其他尺寸，CLI 不写文件并说明实际画布。

  2. 判断是否接受裁切

    如果画面边缘不可丢失，应调整提示词或更换供应商。

  3. 主动修正输出
    gpt-image generate "宽景雪山天文台，主体位于中央" --size landscape --fit-output-size -o ./artifacts/observatory.png

    图片会居中裁切并缩放到 1536×1024，结果统一保存为 PNG。

教程：排查代理连接

  1. 查看当前代理模式
    gpt-image doctor --json

    检查 proxy_mode 是 explicit、environment、windows-system、direct 或 disabled。

  2. 显式验证本地代理
    gpt-image doctor --proxy http://127.0.0.1:7890
  3. 排除代理影响
    gpt-image doctor --no-proxy
  4. 只调整连接阶段
    gpt-image doctor --connect-timeout 60 --connect-retries 3

    已提交的图片请求仍然不会自动重试。

教程：安全检查并更新

  1. 查看当前版本
    gpt-image --version
  2. 只检查公开渠道
    gpt-image update --check --source auto
  3. 诊断单一镜像
    gpt-image update --check --source github
gpt-image update --check --source gitee
gpt-image update --check --source gitcode
  4. 安排已验证更新
    gpt-image update

    当前命令退出后，独立助手才会替换 uv tool 隔离环境。下一次调用 gpt-image --version 验证新版本。

非 uv tool 安装

更新器会拒绝擅自覆盖 pipx、系统包管理器或源码虚拟环境。请用原来的安装方式升级。
